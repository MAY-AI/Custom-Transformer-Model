# **Custom Transformer Model**

**A homebrewed, open-source Transformer Large Language Model (LLM) written in C with minimal dependencies.**

## **Current completion status**

> [!CAUTION]
> This project is incomplete and under active development.

## **How to run:**

This project currently uses `gcc` and a Makefile.

On Windows with MinGW installed:

```powershell
mingw32-make run
```

On Linux or WSL:

```bash
make run
```

If you use another compiler or platform, you may need to modify the
provided Makefile or use your own Makefile.
